# Reference files

Place an [OCP OCDS 1.1 field-level mapping template](https://www.open-contracting.org/resources/ocds-1-1-mapping-template-guidance/) workbook here to regenerate bundled data.

| File | Description |
|------|-------------|
| `OCDS_Mapping_Template_1.1.xlsx` | **Recommended name** — any filled or blank OCP mapping workbook used as the build input |
| `OCDS_Mapping_Template_1.1_blank.xlsx` | Generated by `npm run strip-template` — used by xlsx export when present |
| `2025_mPhilGEPS_OCDS…xlsx` | Shipped — source for `public/projects/mphilgeps.json` |
| `2025_PhilGEPS 1.5_OCDS…xlsx` | Shipped — source for `public/projects/philgeps-1.5.json` |
| `NEW Red Flags to OCDS mapping #Public - *.csv` | OCP public red-flag catalogue (R001–R073) |
| [`OCP_RED_FLAGS_TO_OCDS.md`](OCP_RED_FLAGS_TO_OCDS.md) | Markdown reference generated from those CSVs |

Regenerate the OCP red-flags markdown + app pack:

```bash
python scripts/build_ocp_red_flags_pack.py
# → references/OCP_RED_FLAGS_TO_OCDS.md
# → public/indicator_packs/ocp-red-flags.json
```

## Regenerate app data

```bash
pip install -r requirements.txt
npm run build-data
```

This writes `public/ocds_reference.json` (tier A) and `public/projects/blank.json` (empty inventory).

Regenerate PhilGEPS bundled projects:

```bash
npm run build-philgeps-projects
```

The reference tree includes:

- Mappable **leaf** rows for coverage stats and mapping targets
- **Container** rows (`span`, `ref_span`, …) for object structure
- **`extension_intro`** headers for extension blocks (not OCDS paths)

Custom input/output:

```bash
python scripts/excel_to_json_mapping.py -i references/your-template.xlsx -o dist/mapping_document.json
python scripts/build_project.py -i references/your-template.xlsx --project my-agency --name "My Agency"
```

## Blank template

Strip mapping values from a filled workbook while preserving structure:

```bash
npm run strip-template
# or: python scripts/strip_template.py -i references/filled.xlsx -o references/OCDS_Mapping_Template_1.1_blank.xlsx
```
